# 動物商業王國 V2 - 櫃檯經營與 POS 點餐英文學習遊戲

這是一個專為兒童設計的英文放置/點餐經營遊戲，結合雙軌字幕/語音輔助與 POS 機防盲猜機制。

## GitHub Pages 部署步驟

1. 下載並解壓縮此 ZIP 檔案。
2. 開啟你的 GitHub 專案倉庫（Repository）。
3. 將解壓縮後資料夾內的所有檔案與資料夾（包含 `index.html`、`css/`、`data/`、`js/`、`industries/`）覆蓋/Push 到 GitHub 倉庫中。
4. 進入 GitHub 倉庫的 **Settings** -> **Pages**，確定 Source 選擇 `main` branch 並 Save。
5. 等待數分鐘後即可開啟全新萬用 POS 櫃檯經營版遊戲！
