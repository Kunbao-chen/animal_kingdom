# 動物商業王國 - 課綱連動英文學習遊戲 (Animal Kingdom English)

這是一個專為兒童設計的英文養成遊戲專案，支援動態讀取課綱 JSON 與模組化產業擴充。

## GitHub Pages 部署步驟

1. 解壓縮此 ZIP 檔案。
2. 在 GitHub 上建立一個新的公開專案倉庫（Repository）。
3. 將解壓縮後資料夾內的所有檔案與資料夾（包含 `index.html`、`css/`、`data/`、`js/`、`industries/`）上傳/Push 到 GitHub 倉庫。
4. 進入 GitHub 倉庫的 **Settings** -> **Pages**。
5. 在 **Source** 選擇 `main` branch，並儲存（Save）。
6. 等待數分鐘後，即可透過 GitHub Pages 提供的專屬網址開啟遊戲！
